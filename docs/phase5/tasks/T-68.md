## Việc cần làm
1. `CharacterAvatar({ avatarUrl, fallbackSeed, size })`: đọc `style`/`seed` từ URL dạng
   `https://api.dicebear.com/9.x/<style>/svg?seed=<seed>` (**không fetch**), sinh SVG bằng `@dicebear/core`, `useMemo`;
   style lạ → style mặc định; `alt`/`aria-label` = nickname. Hàm `avatarUrlFor(seed)` + `randomSeed()`.
2. Kiểm giấy phép style chọn ở G1; CC BY → ghi công trong README. Đo bundle; >15 kB gzip → tải lười, hiện vòng tròn
   chữ cái đầu trong lúc chờ.
3. `IdentityMenu`: "N đang xem" (peer còn hạn + mình, chồng ≤3 avatar) mở danh sách Đang xem/Vắng; avatar + tên +
   vai trò mở menu: Mời bạn · Thành viên · Thông tin chuyến · Chiến lược hoà phiếu (host, chưa FINALIZED) ·
   Ngôn ngữ · Giao diện · Âm thanh. Dùng `Sheet` trên mobile, popover trên desktop; Esc đóng, focus trả về nút.
4. Viền avatar của mình = trạng thái kết nối; bỏ pill "Trực tiếp".
5. `JoinRoomModal`: nút "Đổi nhân vật" đổi seed, gửi `avatar_url` khi vào phòng. (Tạo phòng: T-74.)
6. Xoá `GroupPanel` và khoá i18n chỉ nó dùng; `?tab=group` mở menu (T-67 đã ánh xạ).
