# T-103: Nguồn bản đồ tĩnh cả thành phố (bỏ tải theo bbox)

- **Phụ thuộc:** T-101 DONE · **Đợt:** sau MVP
- **Đọc:** `docs/phase7/MAP-POI.md` §4, §6 · `frontend/src/store/useMapStore.ts`, `PoiLayer.ts`
- **Model gợi ý:** Sonnet 5.5 · high · **Ước lượng:** ~80k

## Việc
- `build_places.py` xuất thêm `frontend/public/data/places_{hcm,hn}.geojson` rút gọn (`id,n,k,c,z,s`); lớp quán dùng nguồn
  này (MapLibre cắt tile trong worker); chi tiết quán vẫn qua `GET /pois/{id}`. Bỏ tải bbox ở `useMapStore` cho lớp quán.
- Đo: thời gian tải + parse, khựng khi zoom/pan trên máy yếu (giả lập CPU 4×). Quá 1,5 s hoặc khựng → làm PMTiles
  (`tippecanoe`, `tippecanoe.minzoom`, thư viện `pmtiles`), kiểm Vercel trả `Range` đúng.
