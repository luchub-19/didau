# T-126: Nhóm chat rối + dải ảnh Bùi Viện

- **Phụ thuộc:** T-124 (ảnh từ T-122; nếu chưa có thì dùng tạm ảnh trong `docs/phase11/comps/assets/` và ghi lại)
- **Model:** Sonnet 5.5 · medium · **Cỡ:** S
- **Skill:** `didau-stage`.

## Mục tiêu
Hai phần nhịp cảm xúc: vấn đề (nhóm chat không chốt được, người xa xin vắng) và chất Sài Gòn (ảnh thật).

## Đọc trước
- `docs/phase11/PLAN.md` §3 (10, 12), §4.1 dòng 2–3, §4.5 (dòng chat, ảnh), §4.8.
- Mock v3: `.chat*`, `renderChat`, khối "1. Nhóm chat", `.photo*`.

## Được phép tạo/sửa
- `frontend/src/landing/sections/{ChatStory,PhotoBand}.tsx` (+ CSS cục bộ nếu cần)
- `frontend/src/landing/LandingPage.tsx` (gắn 2 phần), `frontend/src/i18n/locales/{vi,en}.ts` (`landing.chat.*`, `landing.photo.*`)
- test trong `frontend/src/landing/**/__tests__/`, `docs/phase11/PROGRESS.md`

## Việc cần làm
1. `ChatStory`: tin nhắn có avatar (Nobita, Doraemon, Xuka, Xeko mờ hơn vì ở xa), mốc "Thứ Tư" / "Thứ Bảy, 18:40", bộ đếm 53,
   3 chấm đang gõ ≤ 1,1 s, câu chốt. Khối chat là `role="img"` + `aria-label` mô tả (nội dung đọc được một lần, không đọc từng tin).
2. `PhotoBand`: `<img srcset>` 1200/2000 + `sizes="100vw"`, `width/height`, lazy; phủ tối trên/dưới hoà vào nền; câu lớn;
   dòng ghi công là link tới trang Commons (mở tab mới, `rel="noopener"`); alt mô tả cảnh.

## Tiêu chí hoàn thành
- Chạy một lần khi vào màn hình; tier `static` hiện đủ ngay; nếu phần đã ở trong màn hình lúc tải thì không ẩn.
- Ghi công hiện rõ (≥ 4.5:1 trên ảnh nhờ lớp phủ) ở cả 360px.
- CLS của dải ảnh = 0 (có kích thước sẵn).
- `npm run lint && npm test && npm run build` xanh.
