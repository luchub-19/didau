## Việc cần làm
1. Đo bản `npm run build && npm run preview` (không đo dev server): LCP, CLS, TBT trên "Fast 4G" + CPU 4×, 3 lần lấy trung vị;
   kích thước chunk (landing, map, ảnh); xác nhận không có gsap trong chunk landing; số WebGL context sống theo thời gian.
2. Kiểm 360 / 390 / 768 / 1280 / 1440 × VI/EN × giảm chuyển động bật/tắt; bàn phím toàn trang; axe (0 lỗi serious/critical);
   tương phản mọi chữ trên đêm và trên dải vàng.
3. Ảnh cuối + GIF (mở màn, chốt, kéo điểm) vào `screens/final/`.
4. DESIGN: luật thế giới đêm, token, ngữ pháp chuyển động landing, Named Rule "Always-Light Map" nhắc rõ cả landing.
5. PROGRESS: điền G2 với danh sách việc người dùng cần xem + đề xuất xoá code cũ (liệt kê file, không tự xoá).
