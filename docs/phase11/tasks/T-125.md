# T-125: Hero (phố đêm, bốn bạn hội tụ, phòng mẫu, bản đồ mini)

- **Phụ thuộc:** T-123 (`roomSim`), T-124 · **Cổng:** G1 sau task
- **Model:** Opus 5.5 · high · **Cỡ:** L
- **Skill:** `didau-stage`; `impeccable` (animate) để soát chuyển động.

## Mục tiêu
Màn đầu có khoảnh khắc "wow" một lần, và một phòng mẫu bấm được thật trên bản đồ thật.

## Đọc trước
- `docs/phase11/PLAN.md` §3 (5, 6, 11, 13), §4.1 dòng 1, §4.5 (6 dòng đầu), §4.6.
- Mock v3: `.street`, `drawScene`, `renderRiders/slots/placeRiders`, `.app*`, `renderRoom`, `renderPresence/joinOnce`, `syncPins`, ký hiệu `#i-scooter`.
- `frontend/src/landing/logic/roomSim.ts` (T-123), `sound/useSound.ts`, `config.ts` (`MAP_STYLE_URL`, `FALLBACK_MAP_STYLE`),
  `stage/hero/HeroMap.tsx` (cách app đang nạp lazy maplibre: chỉ tham khảo, không import).

## Được phép tạo/sửa
- `frontend/src/landing/hero/**` (Hero, NightStreet, Riders, RoomWindow, các thẻ trong panel)
- `frontend/src/landing/map/**` (module bản đồ chung: nạp lazy, tidy style, marker quán, chụp ảnh rồi huỷ)
- `frontend/src/landing/LandingPage.tsx` (gắn Hero), `frontend/src/i18n/locales/{vi,en}.ts` (`landing.hero.*`)
- test trong `frontend/src/landing/**/__tests__/` (mock `maplibre-gl`), `docs/phase11/PROGRESS.md`, `docs/phase11/screens/`

## Việc cần làm
1. `NightStreet`: SVG sinh từ seed cố định (nhà ống, cửa sổ, 6 bảng hiệu tiếng Việt, đèn đường + quầng sáng một hướng),
   class "lit" bật sau mount; tính sẵn bằng `useMemo`, không vẽ lại khi đổi ngôn ngữ.
2. `Riders`: 4 xe (ký hiệu scooter + avatar `cast.ts` + nhãn tên), điểm dừng dưới tâm cửa sổ (≥ 960px) hoặc giữa (< 960px),
   WAAPI theo bảng §4.5, chạy **một lần**/lượt tải; tier `static` → đứng sẵn; resize chỉ đặt lại vị trí.
3. `RoomWindow`: panel theo `roomSim.view()` (thẻ hoà + gợi ý + "bớt N′" + Chốt + "Vì sao?" mở tại chỗ; thẻ dẫn; thẻ chốt có
   dấu tích + "Làm lại"), 3 quán có nút tim (`aria-pressed`, nhãn i18n), hiện diện 3 avatar → Xeko vào một lần (3,6 s) + toast;
   âm `tick`/`chime` qua engine app (tắt sẵn).
4. `landing/map`: `loadMap()` lazy import `maplibre-gl` + CSS; `tidyStyle`; `placePin()` marker HTML; `snapshotAndRelease(map)`:
   khi `idle` → ảnh canvas + giữ vị trí ghim (đã `project`) → `remove()` (PLAN §4.6: tối đa 1 WebGL context). Lỗi style → lùi
   `FALLBACK_MAP_STYLE`; lỗi hẳn → nền giấy + ghim vẫn đúng chỗ tương đối.
5. Ghim quán trên bản đồ mini đồng bộ phiếu + trạng thái chốt; hover quán ⇄ ghim nổi.

## Tiêu chí hoàn thành
- Test: reducer tích hợp (thả tim phá hoà → thẻ "đang dẫn"; bỏ tim → hoà lại; chốt → mọi tim `disabled`; làm lại); hiện diện
  chỉ thêm Xeko một lần; tier `static` không gọi `animate`.
- Đo: sau khi hero xong, chỉ còn **0** WebGL context sống (ghi cách đo vào PROGRESS); LCP vẫn là tiêu đề.
- Ảnh `docs/phase11/screens/T-125-{1440,390}-{vi,en}.png` (sau mở màn) + 1 ảnh cảnh chốt; GIF mở màn 1440.
- 360px: cửa sổ không tràn, nút tim ≥ 44px; bàn phím đi được hết panel.
- `npm run lint && npm test && npm run build` xanh.
