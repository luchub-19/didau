## Việc cần làm
1. Migration: `members.origin_lat/origin_lng` (nullable, ràng buộc như rooms), `rooms.state_version BIGINT NOT NULL
   DEFAULT 0`, `rooms.max_places_per_member INT NULL` (phòng mới mặc định 2, phòng cũ `NULL`).
2. `PATCH /rooms/{id}/members/me {origin_lat, origin_lng}` (cả hai `null` = xoá; chỉ một `null` = 422). `GET
   /members/me` trả toạ độ của mình; mọi chỗ trả **thành viên khác** (REST, `ROOM_STATE_SYNC`, `MEMBER_*`) chỉ có
   `has_origin`. WS `MEMBER_UPDATED {member_id, has_origin}`.
3. `state_version`: tăng trong cùng transaction ở mọi service có phát WS (một helper chung), đính vào mọi tin WS
   server→client + `ROOM_STATE_SYNC` + header `X-State-Version`.
4. Giới hạn đề xuất: kiểm khi `POST /places` (không tính quán đã xoá), 409 `PLACE_LIMIT_REACHED {limit, used}`; `PATCH
   /rooms` nhận `max_places_per_member` (host, `null` = bỏ giới hạn, 1–10); tạo phòng nhận trường tuỳ chọn.
5. MSW + kiểu TS khớp hợp đồng mới (để T-88 dùng).
