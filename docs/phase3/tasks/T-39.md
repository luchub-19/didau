# T-39: Lõi i18n (vi/en) + lưới an toàn chống sót chữ

- **Mốc:** M1 · **Phụ thuộc:** T-38
- **Đọc:** `DESIGN.md` §9, §10 · `PLAN.md` §2 (đoạn về test môi trường node)
- **Skill áp dụng:** impeccable `harden.md` (mục Internationalization: không ghép chuỗi, số nhiều, `Intl`) và
  `clarify.md` (đoạn "Voice, accessibility, and localization").

## Mục tiêu
Hạ tầng song ngữ hoạt động và **tự bắt lỗi**: thiếu khoá, câu tiếng Việt lọt vào bản EN, chữ hardcode mới. Chưa chuyển
màn hình nào (trừ `App.tsx` cho màn khởi động máy chủ), nhưng mọi task sau chỉ việc gọi `t()`.

## Được phép tạo/sửa
- Tạo: `frontend/src/i18n/index.ts` (khởi tạo), `i18n/locales/vi.ts`, `i18n/locales/en.ts`, `i18n/format.ts`,
  `i18n/useLanguage.ts`, `i18n/i18next.d.ts` (kiểu khoá), `components/ui/LanguageSwitcher.tsx`,
  `__tests__/i18n_parity.test.ts`, `__tests__/i18n_guard.test.ts`, `__tests__/i18n_format.test.ts`
- Sửa: `frontend/src/main.tsx` (import i18n, thay chuỗi lỗi), `frontend/src/App.tsx` (màn waking/error dùng `t()`),
  `frontend/src/hooks/useMinuteFormat.ts` (dùng `format.ts`, giữ chữ ký hàm cũ), `package.json` + lock
- Dependency được thêm: `i18next`, `react-i18next`

## Việc cần làm
1. Khởi tạo **đồng bộ** với tài nguyên gói sẵn (`initImmediate: false` hoặc tương đương ở bản hiện hành), không dùng
   backend tải file. `fallbackLng: 'vi'` chỉ cho khoá; test parity đảm bảo không bao giờ phải fallback.
2. Phát hiện ngôn ngữ đúng `DESIGN.md` §9 (không cần `i18next-browser-languagedetector`, tự viết 15 dòng có guard
   `typeof navigator/localStorage`). `useLanguage()` trả `{lang, setLang}`; `setLang` lưu `didau.lang`, đổi
   `document.documentElement.lang`.
3. `vi.ts` là nguồn, export `const vi = {...} as const`; `en.ts` khai báo `export const en: Messages = {...}` với
   `type Messages = DeepStringify<typeof vi>` để TypeScript báo thiếu/thừa khoá. Khởi đầu với nhóm `common`
   (hành động chung: lưu, huỷ, đóng, thử lại, xoá...), `app` (tên, khẩu hiệu, màn khởi động/lỗi máy chủ), `lang`
   (tên ngôn ngữ: "Tiếng Việt" / "English" hiển thị đúng tên gốc ở cả hai bản).
4. `format.ts`: `formatTime(minute, lang)`, `formatTimeRange`, `formatDuration(min)` ("1 giờ 30 phút" / "1 h 30 min"),
   `formatMoney(vnd)`, `formatDistance(km)`, `formatRelative(date)`, đều dùng `Intl` theo locale `vi-VN` / `en-US`.
   `useMinuteFormat` gọi lại các hàm này (giữ API cũ để component cũ không vỡ).
5. `LanguageSwitcher`: hai nút "VI" / "EN" dạng segmented, `aria-pressed`, nhãn truy cập qua i18n. Task này chỉ
   hiển thị nó trên `/_styleguide` để thử; gắn vào giao diện thật ở T-44 (trang chủ) và T-50 (tab Nhóm).
6. `i18n_guard.test.ts`: đọc mọi `.ts/.tsx` dưới `src/` trừ `i18n/locales/`, `mocks/`, `__tests__/`, `dev/`; bỏ comment
   (`//...`, `/* ... */`, `{/* ... */}`); fail nếu còn ký tự có dấu tiếng Việt. Danh sách chờ `PENDING_FILES` (hằng
   trong chính file test) liệt kê mọi file hiện còn chữ tiếng Việt, kèm comment ghi task sẽ xử lý file đó. Test cũng fail
   nếu một file trong danh sách chờ **đã sạch** (để danh sách chỉ giảm, không sót).
7. `i18n_parity.test.ts`: tập khoá `vi` = `en`; mọi giá trị `en` không chứa ký tự có dấu tiếng Việt (trừ khoá
   `app.name` = "Đi Đâu" và tên ngôn ngữ "Tiếng Việt"); không giá trị rỗng; biến nội suy `{{x}}` khớp giữa hai bản.

## Tiêu chí hoàn thành
- 150 test cũ vẫn xanh (môi trường node → `vi`). Ba test mới xanh. Lint, build xanh.
- Ở `/_styleguide` bấm EN: chữ mẫu của nhóm `common`/`app` đổi sang tiếng Anh, `<html lang="en">`, tải lại trang vẫn EN.
- Màn "đang đánh thức máy chủ" và "không kết nối được" hiển thị đúng hai ngôn ngữ (chụp 390px VI/EN, chặn mạng để thấy).
- PROGRESS ghi số file trong `PENDING_FILES` ban đầu.

## Bẫy đã biết
- `renderToStaticMarkup` không chạy effect: i18n phải sẵn sàng **trước** khi render, không đợi Promise.
- Đừng để `vi.ts` thành file khổng lồ một cấp: nhóm theo tính năng (`room`, `place`, `vote`, `schedule`, `conflict`,
  `map`, `review`, `decide`, `autoplan`, `group`, `errors`). Các task sau thêm khoá vào đúng nhóm.
- `react-i18next` cần `I18nextProvider` hoặc `initReactI18next`; dùng `initReactI18next` để component không phải bọc.
