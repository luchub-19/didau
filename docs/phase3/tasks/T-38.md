# T-38: Token thiết kế, font, bộ icon, trang mẫu

- **Mốc:** M1 · **Phụ thuộc:** – · **Cổng sau task:** người dùng duyệt ảnh trang mẫu
- **Đọc:** `DESIGN.md` §1, §2, §3, §4, §6 (đoạn Icon), §11 · `PLAN.md` §1 · skill gốc tham khảo: impeccable `craft-floor.md`
  (đoạn "Browser surfaces") nếu cần
- **Skill áp dụng:** redesign-skill thứ tự "font → màu" (bước 1–2); impeccable craft-floor: chỉnh bề mặt trình duyệt.

## Mục tiêu
Đặt nền thị giác mà mọi task sau dùng, và cho người dùng **nhìn thấy** coral + Be Vietnam Pro trước khi đầu tư vào
component. Chưa đổi màn hình thật nào.

## Được phép tạo/sửa
- Tạo: `frontend/src/styles/tokens.css`, `frontend/src/styles/base.css`, `frontend/src/dev/StyleGuide.tsx`
- Sửa: `frontend/tailwind.config.js`, `frontend/src/index.css`, `frontend/index.html`, `frontend/src/App.tsx`
  (chỉ thêm nhánh route dev), `frontend/package.json` + lock
- Dependency được thêm: `@fontsource/be-vietnam-pro`, `@phosphor-icons/react`

## Việc cần làm
1. `tokens.css`: mọi token màu ở `DESIGN.md` §2 dưới dạng `--color-*` (giá trị RGB tách kênh để Tailwind dùng được
   `/<alpha>`), cộng 7 cặp màu danh mục `--cat-food`, `--cat-food-soft`... (chọn sao cho icon đậm đạt ≥3:1 trên nền
   soft và trên trắng; ghi tỉ lệ đo được vào Nhật ký), thang z-index, bóng `--shadow-float`, bán kính, token motion
   (§8) khai báo sẵn nhưng chưa dùng.
2. `tailwind.config.js`: `theme.extend.colors` map tên token (`bg`, `surface`, `ink`, `accent`...); `fontFamily.sans`
   = Be Vietnam Pro + fallback `system-ui`; `fontSize` theo thang §3 (`display`, `title`, `heading`, `body`, `label`,
   `caption`, kèm line-height); `borderRadius` (`card: 16px`, `field: 12px`); `zIndex` theo thang. **Giữ** màu
   Tailwind gốc để màn cũ chưa chuyển vẫn chạy (xoá ở T-51).
3. Import font: chỉ subset `vietnamese` + `latin`, weight 400/500/600/700.
4. `base.css`: `body` dùng `bg`/`ink`/font; `::selection` nền `accent-soft`; `caret-color` accent; focus ring
   `:focus-visible` 2px `accent-text` offset 2px; scrollbar mảnh màu `line`; `font-variant-numeric: tabular-nums`
   cho class `.num`; `text-wrap: balance` cho h1–h3.
5. `index.html`: favicon SVG (hình ghim bản đồ coral, vẽ bằng path, không emoji); `theme-color` = `#FAFAF9`;
   bỏ class màu `slate` ở body (đã nằm trong base.css); meta viewport thêm `viewport-fit=cover` (cho safe-area của
   thanh tab dưới ở T-41). Giữ `lang="vi"` (T-39 sẽ cập nhật động).
6. `dev/StyleGuide.tsx`, chỉ hiện khi `import.meta.env.DEV` và URL là `/_styleguide`: bảng màu kèm tên token, thang
   chữ bằng **câu tiếng Việt có dấu chồng** ("Ở đâu? Ổn định chưa? Ể Ỗ Ậ Ừ") và một câu tiếng Anh, mẫu nút
   primary/secondary/ghost/danger (HTML tạm, chưa phải component T-40), chip, thẻ quán mẫu, 7 icon danh mục Phosphor,
   thanh tab dưới mẫu (tĩnh). Mục đích: duyệt mắt.

## Tiêu chí hoàn thành
- `npm run lint && npm test && npm run build` xanh; giao diện các màn cũ không vỡ (vẫn dùng màu Tailwind gốc).
- `/_styleguide` hiển thị đúng font (kiểm tra trong DevTools là Be Vietnam Pro, không phải fallback) và dấu không bị cắt.
- Ảnh chụp `/_styleguide` ở 390px và 1280px lưu vào `docs/phase3/screens/T-38-390.png`, `T-38-1280.png`.
- PROGRESS: cổng "Duyệt trang mẫu T-38" chuyển sang "chờ người dùng xem ảnh". **Hỏi người dùng** trước khi đóng
  session: đồng ý màu/font không, muốn chỉnh gì. Ghi câu trả lời vào PROGRESS.

## Bẫy đã biết
- Chữ trắng trên coral trượt tương phản (2.8:1): nút primary dùng chữ `ink`.
- Tailwind v3 (không phải v4): cấu hình trong `tailwind.config.js`, không dùng `@theme`.
- Build trong Docker/Vercel: font tự host qua npm, không link Google Fonts.
