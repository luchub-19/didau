# T-55: Đánh bóng, tài liệu, review cuối giai đoạn 3

- **Mốc:** M6 · **Phụ thuộc:** tất cả T-38 → T-54
- **Đọc:** `docs/phase3/PROGRESS.md` (toàn bộ), `docs/phase3/AUDIT.md`, `DESIGN.md` §12 · `docs/DEPLOY.md` (chỉ mục
  frontend/Vercel)
- **Skill áp dụng:** impeccable `polish.md` + `audit.md` (chấm lại), `critique.md` (nhìn ảnh như người dùng: thứ bậc,
  rõ ràng, cảm xúc); taste-skill `tells.md` (lần rà cuối).

## Mục tiêu
Khép giai đoạn 3: sửa các điểm nhỏ còn lại, tài liệu cập nhật, bản build deploy được, người dùng có bộ ảnh cuối.

## Được phép tạo/sửa
- Mọi file `frontend/src/` **chỉ để sửa lỗi nhỏ/đánh bóng** đã liệt kê trong AUDIT hoặc phản hồi người dùng
- `README.md` (phần giao diện, song ngữ, cách đổi ngôn ngữ, ảnh chụp), `docs/phase3/AUDIT.md` (điểm sau cùng),
  `docs/phase3/DESIGN.md` (chỉ sửa để khớp thực tế đã làm, ghi rõ thay đổi), `docs/DEPLOY.md` (nếu có biến môi trường
  mới)
- `CLAUDE.md` gốc: chuyển phần "giai đoạn 3" sang trạng thái đã xong, ghi giai đoạn tiếp theo (nếu người dùng muốn)

## Việc cần làm
1. Gom mọi mục "Cho task sau" còn mở trong PROGRESS; làm hoặc ghi lý do không làm.
2. Polish theo `polish.md`: khoảng cách lệch, căn chỉnh icon/chữ, trạng thái hover/focus thiếu, chữ mồ côi tiêu đề,
   bề mặt trình duyệt (selection, scrollbar, focus) đúng token ở cả sáng và tối.
3. Chấm lại `AUDIT.md` (0–4 cho 5 hạng mục), mục tiêu ≥3 ở mọi hạng mục.
4. Hiệu năng: kích thước bundle (so với trước giai đoạn 3: ghi số), font chỉ tải subset cần thiết, map chunk vẫn tách
   riêng; Lighthouse mobile cho trang chủ và phòng (ghi điểm).
5. Bộ ảnh cuối: mọi màn × (390, 1280) × (VI, EN) × (sáng, tối cho 390px), `docs/phase3/screens/final/`.
6. README: mục "Giao diện & ngôn ngữ" (cách đổi VI/EN, chế độ tối), ảnh chụp đại diện.

## Tiêu chí hoàn thành
- Mọi task giai đoạn 3 `DONE`, cổng đã qua, PROGRESS không còn việc mở chưa có quyết định.
- `cd frontend && npm run lint && npm test && npm run build` xanh; nếu có đụng backend (không nên):
  `poetry run ruff check . && poetry run pytest`.
- `docker compose up --build` chạy được và giao diện mới hiển thị qua backend thật (không MSW): ghi kết quả.
- **Hỏi người dùng** duyệt bộ ảnh cuối trước khi commit.
